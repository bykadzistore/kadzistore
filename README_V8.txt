KADZI STORE V8 — GLASS HYBRID RED EDITION

Основа: KADZI_STORE_v7_topup_confirmation.zip.

Что обновлено:
- Единый Glass Hybrid Red Edition: чёрно-красные градиенты, выраженное стекло, смешанные карточки, плавные микро-анимации и reduced-motion поддержка.
- Главная страница сохранена строго по согласованной структуре: бренд, слоган, описание, объявления и кнопка «Открыть магазин». Товаров и категорий на главной нет.
- Магазин остаётся отдельной вкладкой: сначала выбор игры, затем разделы, платформа, поиск и товары выбранной игры.
- Профиль, баланс, заказы, избранное, покупки и пополнение сохранены.
- После заявки на пополнение Mini App остаётся открытым; переход в @ByKadzi выполняется только по отдельной кнопке подтверждения.
- Объявления на главной поддерживают форматы banner/card, изображение, до 4 внешних HTTPS-кнопок и порядок сортировки.
- Админ-панель получила редактирование всех полей объявлений, публикацию/скрытие, сортировку и удаление.

Совместимость backend проверена в подключённом Supabase-проекте vpuaihznkswrpsqxgcvm:
- kds_announcements содержит display_type, image_url, buttons (jsonb), sort_order.
- kds-admin save_announcement принимает эти поля и проверяет HTTPS-ссылки.
- kds-api отдаёт эти поля в Mini App.
- Существующие функции покупок, баланса, заказов, выдачи и Telegram-интеграции не изменялись этим архивом.

Установка:
1. Сделай резервную копию текущих файлов репозитория.
2. Замени index.html и admin.html файлами из архива.
3. Остальные файлы и Supabase не меняй. Миграция для объявлений не нужна: поля уже присутствуют в подключённой базе.
4. Сделай Commit в GitHub Pages и проверь Mini App через Telegram.

Проверено локально: JavaScript синтаксис, HTML IDs для редактора объявлений, архивная структура. Публикация в GitHub Pages не выполнялась.
