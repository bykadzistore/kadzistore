KADZI STORE V9 — FUNCTIONAL UPDATE
Основа: KADZI_STORE_v8_Glass_Hybrid_Red_Edition_FIXED.zip.

Что сделано в V9
1. Рейтинги товаров:
   - Покупатель может поставить от 1 до 5 звёзд только после выполненного заказа.
   - Текстовых отзывов нет.
   - Публичный рейтинг и количество оценок рассчитываются только по оценкам 4 и 5 звёзд.
   - Оценки 1–3 не участвуют в публичной средней оценке.
   - На карточке и странице товара показываются средняя оценка и число публичных оценок.

2. Уведомления покупателей:
   - Подтверждение оплаты.
   - Изменение статуса заказа.
   - Выполнение заказа.
   - Новые объявления.
   - Отдельные переключатели каждого типа находятся в профиле.
   - В приложении есть центр уведомлений; пока Mini App открыта, он обновляется примерно раз в 45 секунд.
   - Важные сообщения с ключом/данными для выдачи не блокируются настройкой уведомлений.
   - Это центр уведомлений внутри Mini App, а не системные push-уведомления телефона.

3. Рассылка объявлений:
   - В редакторе объявления можно отдельно включить уведомление в приложении и/или отправку через Telegram.
   - Перед каждой рассылкой выбирается аудитория: пользователи приложения, пользователи, открывавшие Mini App и доступные в Telegram, либо выбранные Telegram ID.
   - Telegram-сообщение поддерживает кнопки-ссылки объявления.
   - Есть история рассылок с числом отправок и ошибок.
   - Реестр Telegram-получателей пополняется при открытии Mini App; существующие пользователи приложения добавлены в реестр при обновлении.

4. Аналитика в админ-панели:
   - Периоды: сегодня, 7, 30, 90, 360 дней и всё время.
   - Выручка, оценочная себестоимость, валовая прибыль, количество заказов, средний чек, отмены/возвраты.
   - Разбивка по товарам и играм, последние заказы.
   - Себестоимость оценивается как цена в приложении / 1.2, так как цена в приложении уже включает наценку 20%.
   - Прибыль показывается до комиссий: комиссии не хранятся в заказах, поэтому чистую прибыль после комиссии система пока не может достоверно посчитать.

База и сервер
- Миграции KADZI STORE v9 уже применены к подключённому Supabase-проекту.
- Edge Function kds-api-v9 развёрнута (версия 4).
- Edge Function kds-admin обновлена (версия 28).
- Новые таблицы защищены RLS; доступ к ним через anon/authenticated закрыт, серверная работа идёт через service_role.
- Старый kds-api оставлен без изменений, чтобы не затрагивать текущий Telegram webhook.

Установка сайта
1. Сделай резервную копию файлов репозитория.
2. Замени index.html и admin.html версиями из этого архива.
3. Опубликуй изменения в GitHub Pages.
4. Открой Mini App через Telegram и проверь каталог, профиль, уведомления, рейтинг и админ-панель.

Важно про аудиторию Telegram
- В список доступных Telegram-получателей попадают пользователи, которые открывали Mini App. Существующие пользователи приложения перенесены в этот список.
- Пользователи, которые только нажали /start и никогда не открывали Mini App, в этот реестр автоматически не попадают.
