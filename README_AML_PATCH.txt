KADZI STORE — AML / антифрод UI patch

Это архив с патчем для admin.html, а не полный ZIP проекта.
GitHub не разрешил записать обновлённый файл в репозиторий (403).
Серверный AML-бэкенд уже развёрнут.

Как применить:
1. Сделай резервную копию текущего admin.html.
2. Помести patch_admin.py рядом с admin.html.
3. Запусти: python patch_admin.py admin.html
4. Проверь, что появилась вкладка «AML / Антифрод».
5. Загрузи обновлённый admin.html в корень репозитория bykadzistore/kadzistore (main).
6. Открой админку через Telegram Mini App и нажми «AML / Антифрод».

Патч подключает:
- очередь открытых AML-кейсов;
- причины и детали риска;
- действия «Снять отметку» и «Подтвердить риск»;
- список заявок на вывод с риск-флагом;
- обработку выплат/отклонений через существующий серверный API.

Важно:
- Сервер повторно проверяет AML-состояние при попытке отметить выплату как выполненную.
- Сам патч не включает вывод средств.
- Не публикуй секреты Supabase или Telegram-бота.
