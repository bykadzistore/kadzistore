KADZI STORE — пакет интерфейса (исправленная структура архива)

В корне архива находятся:
- index.html — обновлённая главная и каталог Mini App.
- admin.html — текущая рабочая админ-панель без новых функций объявлений.

Что реализовано в index.html:
- Главная без списка товаров; вместо него три демонстрационных объявления.
- Каталог с игровыми фильтрами: Oxide Survival Island, PUBG Mobile, Standoff 2, Mobile Legends, Genshin Impact, Free Fire.
- Карточки открывают подробное описание товара и выбор срока/тарифа.
- Покупка использует существующий API action create_order.
- Адаптивная сетка и окно товара для мобильного экрана.

Что НЕ реализовано в этом пакете:
- Объявления пока статические, не редактируются из админ-панели и не сохраняются в Supabase.
- Управление изображениями товаров/объявлений через админ-панель не добавлено.
- admin.html включён без изменений, чтобы сохранить существующие функции управления заказами, товарами и складом.

Публикация:
1. Сделайте резервную копию текущих файлов.
2. Замените index.html и admin.html файлами из корня архива (не создавайте дополнительную папку).
3. Не загружайте эти HTML-файлы вместо Edge Functions kds-api или kds-admin.

Проверка:
- index.html: встроенный JavaScript прошёл проверку node --check.
- Архив содержит index.html и admin.html непосредственно в корне.
