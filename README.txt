KADZI STORE — обновлённый пакет интерфейса

Файлы:
- index.html — обновлённый интерфейс Mini App.
- admin.html — текущая админ-панель без изменения backend API.

Что обновлено в index.html:
- Главная страница без списка товаров: вместо него три информационные карточки объявлений.
- В каталоге предусмотрены категории игр: Oxide Survival Island, PUBG Mobile, Standoff 2, Mobile Legends, Genshin Impact, Free Fire.
- Карточки товаров открывают подробное описание и выбор тарифа.
- Покупка выполняется из окна товара через существующий action create_order.
- Добавлены адаптивные стили для мобильных экранов.

ВАЖНО:
Это пакет обновления интерфейса, а не полностью завершённый релиз всех запрошенных функций.
Объявления пока статические (3 демонстрационных слота): управление ими из админ-панели и сохранение изображений в Supabase ещё не подключены.
Загрузка изображений товаров из админ-панели также не добавлена. Для полноценного управления объявлениями и изображениями нужно отдельно расширить схему Supabase и backend kds-api / kds-admin.

Перед публикацией сохраните резервные копии текущих index.html и admin.html. Не заменяйте Edge Function kds-api этим архивом: это статические файлы интерфейса.
