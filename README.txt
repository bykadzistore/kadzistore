KADZI STORE - обновление карточек и фильтров

Файлы:
- index.html — каталог: отдельное краткое и полное описание, карточка товара открывает подробное окно, фильтры игры / раздела / платформы, изображения карточек.
- admin.html — управление товарами: игра, Софт/Донат, Android/iOS/PC, краткое и полное описание, HTTPS-ссылка на изображение.

Уже выполнено в подключенном Supabase:
- Все существующие товары сохранены.
- Платформа Android NROOT нормализована до Android.
- Существующие товары отнесены к разделу Софт (они уже имели эту категорию).
- Ограничение платформ расширено до Android, iOS, PC.
- Edge Function kds-admin обновлена для поддержки Android, iOS, PC.

Для публикации:
1. index.html загрузить вместо текущего index.html в GitHub Pages.
2. admin.html загрузить вместо текущего admin.html.
3. Не менять URL API и не удалять другие файлы проекта.

Правила:
- Mobile Legends, Genshin Impact и Free Fire не поддерживают раздел Софт; в админке он отключается автоматически.
- Для остальных игр можно выбрать Софт или Донат.
- Платформы: Android, iOS, PC.
